# Data Structures & Algorithms in C

A collection of data structures and algorithms implemented from scratch in C.

I’m building this repository as a way to understand how different data structures work internally rather than relying on built-in implementations. Each topic is implemented separately with its own source and header files, focusing on the core operations, logic, and common algorithms.

## Structure

```text
data-structures/
├── 1-linked-lists/
├── 2-doubly-linked-lists/
├── 3-circular-linked-lists/

```

## Goals

The main goal of this repository is to build a solid understanding of data structures by implementing them manually and studying their behavior.

I’m also using these implementations to practice:

* Memory management in C
* Pointers and dynamic allocation
* Time and space complexity
* Recursion
* Algorithm design
* Writing modular C code with `.h` and `.c` files

## Language

* **C**

## Note

The purpose of this repository is not to provide the most optimized implementation of every algorithm, but to understand how they work by building them from scratch.
